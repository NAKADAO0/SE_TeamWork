第十二组 · Lab 2

快速体验完整规划编排链路

  1. 在仓库根目录启动后端服务：python -m uvicorn backend.api:app --host 127.0.0.1 --port 8010，浏览器打开 需求工作台。
  2. 选择产品样例（聊天 MVP、内容社区 MVP、校园失物招领 Markdown），或直接粘贴/导入自定义产品的 JSON 或 Markdown 设计规格。
  3. 点击「检查缺口」验证范围、需求、模块与验收口径；缺口清零后点击「确认规格」锁定输入快照。
  4. 选择标准交付或高并行模板，点击「生成工作流」。工作台使用实时 PM Agent 分解任务。
  5. 在任务表、任务详情与依赖图中查看和微调任务或依赖边，点击「校验」执行结构、覆盖率、环路与产物引用检查，再点击「编排」计算资源约束下的执行批次与等待原因。
  6. 调整并发数或角色容量后重新点击「编排」，可直观对比执行批次与槽位分配变化；点击「完整大图 ↗」可在独立全屏 DAG 视图中按批次或依赖拓扑层查看。
  7. 点击「确认版本」固化当前修订为只读版本，并导出完整的 JSON 计划包与 Markdown 清单。
