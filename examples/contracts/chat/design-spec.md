# 聊天 MVP

## 产品范围

复用登录会话，支持单聊文本消息、历史分页及会话隔离。

- 单聊文本消息发送与查询
- 历史消息分页读取
- 会话成员隔离

明确排除：

- 群聊
- 支付
- 音视频通话
- 消息推送

## 需求条目

| 编号 | 行为描述 | 验收条件 |
| --- | --- | --- |
| R1 | 发送文本消息 | 发送后可查到相同消息 ID |
| R2 | 分页读取会话 | 翻页无重复消息 |

## 模块

| 编号 | 职责 | 关联需求 |
| --- | --- | --- |
| M-MSG | 消息写入、鉴权与会话隔离 | R1 |
| M-HISTORY | 游标分页与历史读取 | R2 |
| M-CHAT-UI | 会话输入、发送状态与历史列表界面 | R1、R2 |

## 设计条目

| 编号 | 类型 | 描述 | 关联需求 |
| --- | --- | --- | --- |
| I-SEND-API | interface | POST 消息接口，返回消息 ID | R1 |
| I-LIST-API | interface | GET 历史分页接口，游标分页且无重复 | R2 |
| I-MSG-ENTITY | entity | 消息实体：消息 ID、会话 ID、发送者、正文、创建时间 | R1 |
| I-SESSION-RULE | rule | 非会话成员写入与读取均被拒绝 | R1 |
| P-CHAT-PAGE | page | 会话页：发送框、失败重试、历史列表与加载更多 | R1、R2 |

## 约束

- 复用既有登录会话与 HTTP JSON 接口
- Web 单页工作台演示
- 非会话成员不可读写消息
