# 内容社区 MVP

## 产品范围

支持图文发布、内容流及幂等点赞，复用既有账号体系。

- 图文笔记发布与回读
- 发布内容流展示
- 幂等点赞

明确排除：

- 直播
- 推荐算法训练
- 私信
- 评论

## 需求条目

| 编号 | 行为描述 | 验收条件 |
| --- | --- | --- |
| R1 | 发布图文笔记 | 发布后可读取正文和图片 |
| R2 | 点赞笔记 | 重复点赞只计一次 |

## 模块

| 编号 | 职责 | 关联需求 |
| --- | --- | --- |
| M-NOTE | 笔记正文、媒体引用与发布校验 | R1 |
| M-FEED | 内容流查询与排序 | R1 |
| M-LIKE | 点赞计数与幂等唯一约束 | R2 |
| M-COMMUNITY-UI | 图文编辑、内容流与点赞交互界面 | R1、R2 |

## 设计条目

| 编号 | 类型 | 描述 | 关联需求 |
| --- | --- | --- | --- |
| I-NOTE-API | interface | POST 笔记接口，返回可读取的笔记 ID | R1 |
| I-FEED-API | interface | GET 内容流接口，按发布时间倒序分页 | R1 |
| I-LIKE-API | interface | POST 点赞接口，同一用户对同一笔记幂等 | R2 |
| I-NOTE-ENTITY | entity | 笔记实体：笔记 ID、作者、正文、图片引用列表、发布时间 | R1 |
| I-MEDIA-RULE | rule | 图片类型与数量校验规则，校验失败拒绝发布 | R1 |
| I-LIKE-RULE | rule | 同一用户对同一笔记的点赞唯一约束 | R2 |
| P-COMMUNITY-PAGE | page | 社区页：图文编辑、预览、内容流与点赞按钮 | R1、R2 |

## 约束

- 复用既有账号体系与 HTTP JSON 接口
- Web 单页工作台演示
- 仅登录账号可发布与点赞，作者与点赞人身份由会话决定
- 本地 SQLite 存储，演示环境不引入外部对象存储
