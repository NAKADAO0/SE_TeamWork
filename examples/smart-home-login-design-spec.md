# 智能家居控制 App V2.0 · 用户登录与注册

文档版本 v1.1，最后更新 2026-11-18。设计负责人和设计稿链接待补。

## 产品范围

通过手机短信验证码打通新老用户的准入链路，降低首日注册流失率。面向 iOS 和 Android 手机竖屏。

- 手机号和六位短信验证码登录，未注册号码自动注册。
- 区号选择支持中国大陆及港澳台。
- 获取验证码与登录前检查用户协议和隐私政策。

明确排除：

- 微信、Apple ID 和 Google 快捷登录
- 邮箱注册、密码和找回密码
- Face ID 和指纹登录
- PC 及平板横屏适配

## 需求条目

| 编号 | 行为描述 | 验收条件 |
| --- | --- | --- |
| REQ-001 | 输入手机号时即时校验，展示清空图标 | 在支持的设备上打开数字键盘，过滤非数字。对于 +86，限制 11 位，按 3-4-4 展示并提交无空格数字。有内容时可一键清空，清空后仍聚焦。 |
| REQ-002 | 格式合法且已同意协议时请求短信验证码，成功后进入验证码页 | 无效号码时按钮禁用且无网络请求。请求期间显示 Loading 并防止重复提交。成功后开始 60 秒倒计时，离开后再进入按实际时间继续，返回再进入示例剩 20 秒。 |
| REQ-003 | 未同意用户协议及隐私政策时拦截主操作 | 不发送请求，屏幕居中出现黑底白字提示「请先阅读并同意用户协议」2000ms，勾选框水平抖动 ±4px、300ms。 |
| REQ-004 | 输入六位验证码后提交登录或自动注册 | 正确验证码下，已注册号码登录，未注册号码自动创建账号后登录。错误验证码不建立会话，并保留重试入口。 |
| REQ-005 | 支持选择中国大陆及港澳台区号 | 选择后显示当前区号，提交区号及纯数字号码；+86 格式规则仅用于大陆号码，其余区号具体长度和格式与接口契约确认。 |
| REQ-006 | 处理网络超时和输入异常 | 请求超过 10 秒结束 Loading，顶部显示「网络连接超时，请检查网络后重试」。输入框错误状态为红色边框，提示文字距边框 4px。 |

## 模块

| 编号 | 职责 | 关联需求 |
| --- | --- | --- |
| M-LOGIN | 手机号录入、区号与协议交互 | REQ-001、REQ-003、REQ-005 |
| M-SMS | 验证码请求、Loading、倒计时与异常处理 | REQ-002、REQ-006 |
| M-AUTH | 验证码校验、账号创建和会话建立 | REQ-003、REQ-004、REQ-006 |

## 设计条目

| 编号 | 类型 | 描述 | 关联需求 |
| --- | --- | --- | --- |
| P-LOGIN | page | 手机号输入页包含区号、清空图标、协议控件和发送按钮 | REQ-001、REQ-002、REQ-003、REQ-005 |
| P-CODE | page | 验证码页包含六位输入、剩余时间和重试提示 | REQ-002、REQ-004、REQ-006 |
| I-SMS | interface | 发送验证码接口接收区号与无空格号码，返回发送结果；具体路径待确认 | REQ-002、REQ-005、REQ-006 |
| I-AUTH | interface | 登录接口接收区号、号码与验证码，验证后登录或自动注册；具体路径待确认 | REQ-003、REQ-004、REQ-006 |
| D-STATES | rule | 记录短信成功时间以计算剩余倒计时。输入边框默认 1px #E5E6EB，聚焦 1.5px #1677FF，报错 1px #F53F3F。 | REQ-001、REQ-002、REQ-006 |

## 约束

- 平台：iOS 15.0+ / Android 11.0+，手机竖屏，基准 375 × 812 px。
- 色彩：主色 #1677FF，按压 #0958D9，正文 #1D2129，辅助文字 #86909C，错误 #F53F3F，边框 #E5E6EB，禁用主按钮 #94BFFF。
- 字体：iOS PingFang SC / SF Pro，Android Noto Sans SC / Roboto。标题 24/32px 半粗，正文和输入 16/24px，说明 12/18px。
- 布局：左右间距 24px，输入和主按钮高度 48px，圆角分别为 8px 和 24px。
- 资源交付：图标交付 SVG、@2x 和 @3x PNG，命名如 ic_login_close.svg。Loading 使用 Lottie JSON，单文件 15KB 以内。
