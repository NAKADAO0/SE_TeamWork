# 校园实验设备借用平台

## 产品范围

面向本校师生和实验室管理员，提供设备查询、时段预约、审批、领用和归还。首期使用校内统一账号，覆盖一个实验室的可移动设备。

- 师生查询设备与可预约时段，提交或取消预约
- 管理员审核申请，登记领用与归还
- 师生查看预约及借用状态

明确排除：

- 付费、押金和在线支付
- 跨实验室借调及硬件门禁
- 校外用户注册

## 需求条目

| 编号 | 行为描述 | 验收条件 |
| --- | --- | --- |
| R-EQ-01 | 按设备名称、类别和时间段查询可借设备 | 同时选择类别和时段时，只显示匹配类别且未停用、无重叠预约的设备 |
| R-EQ-02 | 师生选择设备和起止时间提交申请 | 成功返回唯一申请编号；两个用户同时提交同一设备重叠时段，只接受一条，另一条返回 409 |
| R-EQ-03 | 管理员审核申请，可同意或填写原因后拒绝 | 管理员可审核待审批记录；普通用户尝试审核返回 403；拒绝后时段重新可预约 |
| R-EQ-04 | 申请人在领用前取消自己的预约并释放时段 | 取消后本人可在历史中查看记录，其他人可预约该时段；不能取消他人或已领用的记录 |
| R-EQ-05 | 管理员登记设备领用及归还，申请人可查状态 | 仅已批准的预约可登记领用；归还后状态为已归还，重复归还不会新增记录 |

## 模块

| 编号 | 职责 | 关联需求 |
| --- | --- | --- |
| M-EQ-CATALOG | 管理设备目录与可借时段查询 | R-EQ-01 |
| M-EQ-BOOKING | 管理申请、时段占用和取消 | R-EQ-02、R-EQ-04 |
| M-EQ-ADMIN | 审批申请并登记领用和归还 | R-EQ-03、R-EQ-05 |
| M-EQ-WEB | 提供设备列表、我的预约和管理工作台 | R-EQ-01、R-EQ-02、R-EQ-03、R-EQ-04、R-EQ-05 |

## 设计条目

| 编号 | 类型 | 描述 | 关联需求 |
| --- | --- | --- | --- |
| I-EQ-LIST | interface | GET /equipment 按名称、类别及起止时间查询 | R-EQ-01 |
| I-EQ-BOOK | interface | POST /reservations 创建预约并返回申请编号 | R-EQ-02 |
| I-EQ-REVIEW | interface | POST /reservations/{id}/review 提交审批决定及原因 | R-EQ-03 |
| I-EQ-CANCEL | interface | POST /reservations/{id}/cancel 取消预约 | R-EQ-04 |
| I-EQ-HANDOVER | interface | POST /reservations/{id}/handover 登记领用或归还动作 | R-EQ-05 |
| D-EQ-RESERVATION | entity | 预约包含设备、申请人、起止时刻、状态和审批记录 | R-EQ-02、R-EQ-03、R-EQ-04、R-EQ-05 |
| D-EQ-TIME | rule | 时段为左闭右开，待审批、已批准和已领用占用时段；检查重叠与创建申请使用同一事务 | R-EQ-01、R-EQ-02、R-EQ-04 |
| P-EQ-WEB | page | 提供设备筛选、预约表单、状态历史和管理员待办页面 | R-EQ-01、R-EQ-02、R-EQ-03、R-EQ-04、R-EQ-05 |

## 约束

- 技术栈：Python、SQLite 和浏览器网页
- 平台：校园内部网络，桌面及移动浏览器可用
- 身份：复用校园统一登录，管理员角色由服务端核验
- 时间：显示使用 Asia/Shanghai，预约结束时间必须晚于开始时间
- 数据：历史审批、取消和领还记录保留供查询
